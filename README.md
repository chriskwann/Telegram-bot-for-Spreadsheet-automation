# Telegram Google Sheets Bot (n8n Automation)

This project contains an n8n workflow that:
- Reads customer list from Google Sheets
- Processes user questions via Telegram Bot
- Updates specific rows (e.g., Bailey Ltd, staff count > 100)
- Responds automatically through Telegram

## How to import
1. Download workflow.json
2. Open n8n
3. Import workflow → upload file
